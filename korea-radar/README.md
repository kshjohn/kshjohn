# Korea Radar

**폴란드 언론이 한국을 언급하면 1~2주 안에 "한국인이 진짜 사정을 설명한다" 영상으로 받아치기 위한 모니터.**

## 화면 구성

- **지금 받아칠 이슈** — 여러 매체가 같은 한국 이슈를 다룬 헤드라인을 하나로 묶고, 첫 보도일 기준 반응 창(14일)을 표시합니다. `지금 제작`(7일 이내) → `마감 임박`(8~14일) → `창 닫힘`.
- **교집합 표시** — 토픽마다 관객 성격을 붙였습니다. 저출산·교육·노동·주거/결혼·병역은 `교집합`(20~30대 여성과 30~50대 남성이 둘 다 클릭), K-컬처는 `여성 쏠림`, 방산·기업은 `남성 쏠림`.
- **헤드라인 피드** — Google 뉴스 폴란드판 검색(9개 검색어) + r/Polska 검색 결과. 토픽·기간·교집합 필터, 한국어 번역 링크.
- **토픽별 언급량 / 일별 추이** — 최근 7일 대 직전 7일, 30일 일별 건수.
- **영상 후보** — 담아둔 이슈의 제작 마감(D-n)과 단계(후보 → 대본 → 제작 → 게시). 브라우저 `localStorage`에만 저장됩니다.
- **폴란드어 위키백과 조회수** — 한국 관련 문서의 30일 추이와 급증 표시.
- **직접 확인할 곳** — 자동 수집이 안 되는 Wykop 태그, Reddit 검색, Google Trends, YouTube 링크.

## 동작 방식

- 의존성 없는 단일 `index.html`. GitHub Pages에서 그대로 동작합니다 → `https://kshjohn.github.io/kshjohn/korea-radar/`
- 수집은 전부 브라우저에서 합니다. Google 뉴스 RSS는 공개 CORS 프록시(allorigins → corsproxy.io → codetabs 순서로 자동 전환)를 거치고, Wikimedia와 Reddit은 직접 호출합니다.
- 수집한 헤드라인은 `localStorage`에 45일간 누적됩니다. 자주 열수록 추이 기록이 정확해집니다. 30분 안에 다시 열면 재수집하지 않습니다(새로고침 버튼으로 강제 수집).

## 고치는 곳 (`index.html` 상단의 설정)

| 상수 | 내용 |
|---|---|
| `QUERIES` | Google 뉴스 검색어. 새 주제를 추적하려면 여기에 한 줄 추가 |
| `TOPICS` | 토픽 이름, 관객 성격(`aud`), 제목 분류용 폴란드어 키워드 정규식 |
| `WIKI` | 조회수를 볼 폴란드어 위키백과 문서 제목 (없는 문서는 자동으로 숨김) |
| `WINDOW_DAYS`, `PRIME_DAYS` | 반응 창 길이(기본 14일 / 7일) |
| `MANUAL` | 직접 확인할 링크 목록 |

## 한계

- 토픽 분류와 이슈 묶음은 제목 키워드 기반 근사치입니다.
- Google 뉴스 RSS는 검색어당 최대 100건이라 뉴스가 몰린 주에는 오래된 날짜가 덜 잡힙니다.
- 공개 CORS 프록시가 모두 막히면 그 순간에는 지난 기록만 보입니다.
- Wykop은 공개 API가 없어 링크로만 제공합니다.

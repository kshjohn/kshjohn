# 🇵🇱 Polski A1–C1 · 폴란드어 자습실

**A1부터 C1까지 혼자 익히는 폴란드어 학습 앱.** 브라우저에서 바로 열리고,
홈 화면에 추가하면 설치형 앱처럼 전체 화면으로 뜨며 **비행기 모드에서도 그대로 돌아갑니다.**

👉 **https://kshjohn.github.io/polski-a1c1/**

## 담고 있는 것

| 화면 | 내용 |
|---|---|
| **홈** | 레벨별 진도, 외운 단어 수, 최근 퀴즈 평균, 오늘 할 일 |
| **단어** | 주제별 단어장 62개 · 표제어 1,870개 — 카드 뒤집기·발음 듣기·예문·검색 |
| **격** | 7격의 쓰임과 전치사, 명사 123개의 격변화표, 격마다 고정된 색 표시 |
| **어미** | 동사 66개 활용표, 형용사 41개, 분사·비교급 |
| **숫자** | 수사, 시간, 날짜 읽기 |
| **문법** | 39개 레슨 + 빈칸 채우기 연습 |
| **훈련** | 받아쓰기, 폴→한, 한→폴, 5지선다 |
| **퀴즈** | 격·성·어미 객관식 21종, 오답 노트 |
| **모의고사** | 실전 형식 종합 시험 |

레벨(A1·A2·B1·B2·C1)을 고르면 **그 레벨까지의 내용만** 보입니다. A2를 고르면 A1도 포함됩니다.

## 휴대폰에서 앱처럼 쓰기

- **iPhone / iPad (Safari)** — 위 주소를 연 뒤 공유 버튼 → **홈 화면에 추가**
- **Android (Chrome)** — 주소를 연 뒤 주소창의 **설치** 아이콘, 또는 앱 안 **더보기 → 앱으로 설치**

설치하면 주소창 없이 전체 화면으로 뜨고, 아이콘·이름·테마가 시스템에 등록되며,
한 번 연 뒤에는 **네트워크 없이도** 열립니다.

## 모바일에서 달라지는 것

- **하단 탭 바** — 홈 · 단어 · 문법 · 훈련 · 더보기. 나머지 화면(격·어미·숫자·퀴즈·모의고사)과
  레벨·테마·초기화는 **더보기 시트**에 모았습니다.
- **단어 카드 스와이프** — 뜻을 본 뒤 **오른쪽으로 밀면 「알아요」**, **왼쪽으로 밀면 「헷갈려요」**.
  버튼은 화면 아래에 고정되어 예문이 길어도 손가락이 닿습니다.
- 상단에 현재 학습 범위 칩(A1–B1 등), 터치에 맞춘 버튼 크기, 확대를 유발하지 않는 입력창,
  노치·홈 인디케이터 안전 영역 처리, 시스템 다크 모드 연동.
- 뒤로 가기로 이전 탭으로 돌아갑니다(주소의 `#/vocab` 형태).

데스크톱에서는 기존 상단 탭 UI가 그대로 유지됩니다.

## 진도 저장

진도(외운 단어·레슨·퀴즈·시험 기록)는 **기기 안 브라우저 저장소에만** 남습니다.
서버로 보내지 않으므로 기기를 바꾸면 따라가지 않습니다.
홈 화면 **더보기 → 진도 초기화**로 지울 수 있고, 앱 안의 **백업 코드**로 다른 기기에 옮길 수 있습니다.

## 구성

```
polski-a1c1/
├── index.html            앱 전체 (데이터·화면·모바일 레이어까지 한 파일)
├── manifest.webmanifest  이름·아이콘·시작 주소 — 설치에 쓰인다
├── sw.js                 서비스 워커 — 오프라인 캐시
└── icons/                아이콘 (192·512·maskable·apple-touch·favicon)
```

의존성 없음, 빌드 없음. `index.html`을 그냥 열어도 동작하지만
**설치·오프라인은 `https://`로 서비스될 때만** 켜집니다(서비스 워커 요구 사항).

로컬에서 확인하려면:

```bash
cd polski-a1c1
python3 -m http.server 8099   # http://localhost:8099
```

## 고칠 때

- 내용·화면을 고쳤다면 `sw.js`의 `VERSION` 값을 올리세요. 예전 캐시가 정리되고,
  이미 설치한 사람에게는 앱 안에서 **「새 버전이 있습니다」** 알림이 뜹니다.
- HTML은 항상 네트워크를 먼저 시도하고(3.5초) 실패하면 캐시로 넘어갑니다.
  따라서 온라인에서는 새로고침만으로 최신 내용을 받습니다.

## 알아 둘 점

- 🔊 발음은 브라우저 음성 합성(`pl-PL`)을 씁니다. 기기에 폴란드어 음성이 없으면 소리가 나지 않을 수 있습니다.
  iOS는 *설정 → 손쉬운 사용 → 음성 콘텐츠*, Android는 *설정 → 언어 → 음성 출력*에서 내려받을 수 있습니다.
- 브라우저 저장소가 막힌 환경(시크릿 모드 등)에서는 진도를 주소(`#p=`)에 담아 새로고침을 견딥니다.
  이때는 화면 이동 기록(`#/`)을 쓰지 않습니다.
